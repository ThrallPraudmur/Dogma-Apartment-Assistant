# DOGMA · чат подбора квартир

Готовое Streamlit-приложение на данных dogma.ru. Принимает запрос на русском, уточняет неоднозначные условия, ищет в SQLite и возвращает топ-3/5 с объяснениями, ссылками и JSON. Есть отдельный поиск по фильтрам без API-ключа.

## Публикация в Streamlit Community Cloud

2. В https://share.streamlit.io создать приложение и выбрать репозиторий, ветку и файл `app.py`.
3. В Advanced settings выбрать Python 3.12 и добавить Secrets:

```toml
OPENROUTER_API_KEY = "КЛЮЧ"
OPENROUTER_MODEL = "inclusionai/ling-3.2-flash:free"
```

4. Нажать Deploy и проверить чат по выданной ссылке. Если файлы загружены в подпапку репозитория, указать путь к `app.py` внутри неё.

Для первого запуска каталог поставляется вместе с проектом. Приложение читает SQLite, не изменяет её и не парсит сайт на каждый запрос. Обновление данных запускается отдельно; после него нужно обновить оба файла снимка и перезапустить приложение. Постоянное хранилище и фоновый планировщик для демонстрации не требуются.

## Скрипт или сервис для парсинга данных

```powershell
npm run scrape
```

- Каталог: https://dogma.ru/kvartiry
- POST https://service.dogma.ru/api/layouts-filter/v4/objects/filter
- Параметры: `type=1`, `statuses=[2]`, `limit=100`, `offset`, `group_by=""`, сортировка ID по возрастанию; город не ограничен.
- `type=1` — квартиры. `statuses=[2]` соответствует параметрам публичного каталога. Другие статусы, включая проданные, в эту выборку не входят. Сохраняется исходный `status_code`; `catalog_available` — внутреннее обозначение выборки, не официальная расшифровка статуса.
- Цена: положительная `cost_sale`, иначе `cost`. Сохраняются и базовая, и акционная цены. Деньги — рубли, площадь — м², ID стабилен в рамках источника.
- Ссылки: `https://dogma.ru/flat/{id}`.
- HTTP-ошибки повторяются до трёх попыток. Пауза между страницами, таймаут, дедупликация ID, проверка обязательных полей. JSON сохраняется через временный файл, SQLite — транзакцией. Ошибка загрузки до сохранения оставляет предыдущие данные.

Снимок от 18.11.2026: 14 994 квартиры, 14 ЖК. Во время сбора количество лотов менялось с 14 997 до 14 994, поэтому `complete=false`. Это намеренная отметка ограничений согласованности, а не скрытая ошибка. Offset-пагинация динамического каталога не гарантирует идеальный срез даже при стабильном count. В метаданных есть время начала/окончания, количество строк, дубликаты и факт изменения count. JSON и SQLite не составляют единую транзакцию; при переносе обновляйте оба файла. Python-приложение проверяет совпадение количества строк.

## Логика подбора квартир по параметрам

У нас пользовательский запрос проходит через два преобразования: текст → параметры → SQL. Модель участвует только в первом.

1. Модель извлекает параметры

Пользователь пишет:
Найди студию в ГРЕЙД до 7 млн рублей, от 30 м².

OpenRouter возвращает структурированные условия:
{
  "project": "ГРЕЙД",
  "rooms": 0,
  "budget_max": 7000000,
  "area_min": 30
}
Python проверяет значения и объединяет их с ранее заданными условиями диалога.

2. Python собирает SQL из заранее разрешённых условий

`agent.py` разрешает только модели `:free` и `openrouter/free`, не настраивает платных fallback-моделей. Бесплатные модели могут быть перегружены или недоступны. Для 429 показывается понятная ошибка; предыдущие фильтры сохраняются. При невалидном JSON — одна корректирующая попытка, затем ошибка без изменения состояния. Таймаут API: 10 секунд соединение и 45 секунд чтение. Между запросами одного сеанса — минимум 2 секунды; общего многопользовательского rate limiter нет.

Модель возвращает изменения в `filters`, а также `remove_filters`, `reset_filters`, `needs_clarification`, `clarification_question`. Слияние выполняется кодом. Только валидные подтверждённые условия становятся текущими. Уточнения учитывают предшествующий запрос через историю. Поиск не ослабляет условия при нуле результатов.

Сортировка: цена по возрастанию → площадь по убыванию → ID. Объяснения строятся из данных и ограничений обычным кодом. Студия — `rooms=0`. Частичное имя ЖК разрешается только при одном совпадении; при нескольких требуется уточнение. Есть явные алиасы «Догма Парк» и «Самолёт».

Сейчас память — это состояние текущего сеанса Streamlit, состоящее из двух частей:
- Фильтры: ЖК, бюджет, площадь, комнаты.
- История: последние 30 сообщений; из них последние 12 передаются модели.

Для демонстрации отдельных примеров лучше нажимать «Новый поиск», а для последовательного уточнения — продолжать текущий диалог. 

Ответ — словарь:

```json
{
  "filters": {"project":"ГРЕЙД","budget_max":7000000,"area_min":30},
  "answer": [{"id":198812,"project":"ГРЕЙД","price_rub":6097240,"area_m2":31.3,"rooms":1,"floor":10,"url":"https://dogma.ru/flat/198812","explanation":"Цена и площадь соответствуют заданным условиям."}],
  "explanation": "Варианты по возрастанию цены, затем по убыванию площади.",
  "total_matches": 219,
  "needs_clarification": false,
  "snapshot_at": "2026-11-18T12:16:24.283Z",
  "snapshot_complete": false
}
```
